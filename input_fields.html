📝 About Me Text Area

About Me Text Area with Word Count

✨Key Features

  • Multi-line text input (minimum 5 lines)
  • Real-time word count display (1/200 words)
  • Maximum 200 words validation
  • Visual feedback when limit exceeded (red text)
  • Positioned word counter overlay (bottom-right)
  • Required field validation with custom messages

📝 Complete Implementation

about_me_field.dart 
Stack(
  children: [
    Padding(
      padding: EdgeInsets.only(bottom: 0.h),
      child: CustomTextField(
        validator: (value) {
          // Check if empty
          if (value == null || value.trim().isEmpty) {
            return 'Please enter about yourself';
          }
          // Count words and validate
          int words = value.trim().split(RegExp(r'\s+')).length;
          if (words > 200) {
            return 'Maximum 200 words allowed';
          }
          return null;
        },
        controller: controller.textController,
        labelText: 'About Me',
        minLines: 5,
      ),
    ),
    // Word counter overlay
    Positioned(
      bottom: 10,
      right: 10,
      child: Obx(
        () => Text(
          '${controller.wordCount.value}/200 words',
          style: TextStyle(
            color: controller.wordCount.value > 200
                ? Colors.red
                : Colors.grey,
            fontSize: 12,
          ),
        ),
      ),
    ),
  ],
)

✅ Validation Rules

Badge Condition Error Message
Required Field is empty or contains only whitespace "Please enter about yourself"

🔢 Word Count Logic

word_count_logic.dart 
// Controller method for real-time word counting
void updateWordCount() {
  String text = textController.text.trim();
  if (text.isEmpty) {
    wordCount.value = 0;
  } else {
    // Split by whitespace and count
    wordCount.value = text.split(RegExp(r'\s+')).length;
  }
}
⚠️ Important Note: The word counter updates in real-time using GetX reactive programming. The text color changes to red when exceeding 200 words, providing immediate visual feedback to the user. Make sure to add the text controller listener in the controller's onInit() method.

🎮 GetX Controller

The DriverProfileController manages the state and logic for all form fields using GetX state management. It handles text controllers, word counting, and ensures proper resource cleanup.

📝 Complete Controller Implementation

driver_profile_controller.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:image_picker/image_picker.dart';

class DriverProfileController extends GetxController {
  // Observable word count for About Me field
  RxInt wordCount = 0.obs;
  final int maxWords = 200;
  
  // Image picker for profile photo (optional feature)
  XFile? selectedImage;
  
  // Date of Birth controller with default placeholder
  final TextEditingController dateTime = TextEditingController(
    text: 'DD-MM-YYYY',
  );
  
  // About Me text controller
  final TextEditingController textController = TextEditingController(text: ' ');

  @override
  void onInit() {
    super.onInit();
    // Add listener for real-time word counting
    textController.addListener(updateWordCount);
  }

  /// Updates word count whenever text changes
  /// Splits text by whitespace and counts resulting words
  void updateWordCount() {
    String text = textController.text.trim();
    if (text.isEmpty) {
      wordCount.value = 0;
    } else {
      // RegExp matches one or more whitespace characters
      wordCount.value = text.split(RegExp(r'\s+')).length;
    }
  }

  @override
  void onClose() {
    // Clean up controllers to prevent memory leaks
    textController.dispose();
    dateTime.dispose();
    super.onClose();
  }
}

📊 Controller Properties

Property Type Purpose
wordCount Reactive RxInt Reactive word count for About Me field (auto-updates UI)
maxWords int Maximum allowed words (200)
selectedImage Optional XFile? Stores selected profile image (if needed)
dateTime TextEditingController Controls Date of Birth field
textController TextEditingController Controls About Me text field

✨ Best Practices & Tips

📝 Form Validation

  • Always wrap form fields in a Form widget with GlobalKey
  • Validate on submit, not on every keystroke
  • Provide clear, helpful error messages
  • Use visual indicators for validation status

🎮 State Management

  • Dispose of controllers in onClose()
  • Use Rx variables for reactive updates
  • Keep business logic in controller
  • Initialize in onInit(), cleanup in onClose()

👤 User Experience

  • Provide visual feedback for all actions
  • Use appropriate keyboard types
  • Show loading indicators for async ops
  • Implement smooth transitions

♿ Accessibility

  • Ensure sufficient color contrast
  • Provide semantic labels
  • Make touch targets 48x48 dp minimum
  • Test with screen readers
⚠️ Common Pitfalls to Avoid:
  • Forgetting to dispose of TextEditingControllers (memory leaks)
  • Not using readOnly for date picker fields (allows invalid manual input)
  • Hardcoding strings instead of using localization
  • Not handling edge cases in word count (empty strings, special characters)

🔧 Troubleshooting Guide

❌ Issue: Date picker not showing

Solution: Ensure you have proper context available. If using in a custom widget, pass context as a parameter. Also make sure the field is not disabled.

❌ Issue: Word count not updating

Solution: Make sure the listener is added in onInit() and the controller is properly initialized with Get.put(). Check that you're using Obx() wrapper for reactive updates.

❌ Issue: IntlPhoneField not found

Solution: Run flutter pub get to install the intl_phone_field package. Make sure it's added to pubspec.yaml with the correct version.

❌ Issue: Memory leak warnings

Solution: Always dispose of TextEditingControllers in the controller's onClose() method. GetX will automatically call this when the controller is removed.

❌ Issue: .h extension not working

Solution: Install and initialize flutter_screenutil package. Initialize it in your main.dart with ScreenUtil.init(context, designSize: Size(375, 812)).

❌ Issue: Phone number validation failing

Solution: IntlPhoneField has built-in validation. Make sure you're accessing the complete number correctly using phone.completeNumber in the onChanged callback.
