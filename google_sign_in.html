Complete Flutter & Firebase Integration Documentation

1Firebase Project Setup

Create Firebase Project

  1. Navigate to Firebase Console and create a new project
  2. Add your Flutter app to the Firebase project
  3. Select platform: Flutter
  4. Click NEXT

Install FlutterFire CLI

Run the following command to activate the FlutterFire CLI globally:

dart pub global activate flutterfire_cli

Configure FlutterFire

Connect your Flutter project to Firebase (replace fir-3f430 with your project ID):

flutterfire configure --project=fir-3f430

Initialize Firebase in Your App

Add the following code to your main.dart file in the runApp function:

WidgetsFlutterBinding.ensureInitialized();
await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
);

2Required Dependencies

Install Flutter Packages

Add the following dependencies to your Flutter project:

Core Firebase Package

flutter pub add firebase_core

Firebase Authentication

flutter pub add firebase_auth

Google Sign-In (Android & Common)

flutter pub add google_sign_in

Recommended stable version: ^6.2.1

💡 If you encounter issues, use this specific version and read the package documentation carefully.

Google Sign-In (iOS)

flutter pub add google_sign_in_ios

Recommended stable version: 5.7.5

💡 Remember: iOS requires a separate package!

3iOS Configuration

⚠️ Important iOS Setup Steps

Follow these steps carefully to configure iOS integration:

Step 1: Download GoogleService-Info.plist

Download the GoogleService-Info.plist file from Firebase Console

Step 2: Place the File

Navigate to:

ios/Runner/info.plist

Place the GoogleService-Info.plist file in this location

Step 3: Configure info.plist

Open ios/Runner/info.plist and add the following configurations:

Add Client ID

<key>GIDClientID</key>
<!-- Copied from GoogleService-Info.plist key CLIENT_ID -->
<string>[YOUR IOS CLIENT ID]</string>

Add Server Client ID

<key>GIDServerClientID</key>
<string>[YOUR SERVER CLIENT ID]</string>

Add URL Schemes

<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <!-- Copied from GoogleService-Info.plist key REVERSED_CLIENT_ID -->
            <string>com.googleusercontent.apps.861823949799-vc35cprkp249096uujjn0vvnmcvjppkn</string>
        </array>
    </dict>
</array>

4Firebase Console Configuration

Enable Google Sign-In

  1. Go to Firebase Console
  2. Navigate to: Build → Authentication → Sign-in Method
  3. Click on Google provider
  4. Toggle the Enable switch
  5. Set your support email (the email that will be shown to users)
  6. Set your project name (displayed in the sign-in popup)
  7. Click Save

📸 Visual Reference

The Firebase Authentication setup page should show Google as an enabled sign-in provider with a green status indicator.

5SHA-1 & SHA-256 Configuration

🔐 Critical Security Setup

You MUST add both SHA-1 and SHA-256 fingerprints to Firebase for Google Sign-In to work properly.

Where to Add Fingerprints

  1. Go to Firebase Console
  2. Click on Project Settings (gear icon)
  3. Navigate to: Project Overview → General
  4. Scroll down to Your apps section
  5. Click Add fingerprint

Method 1: Using Gradle (Recommended)

Open Terminal in your project root and run:

cd android
./gradlew signingReport

This will display SHA-1 and SHA-256 keys for all build variants.

Method 2: Using Keytool (Windows)

For CMD (Command Prompt)

keytool -list -v -alias androiddebugkey -keystore "%USERPROFILE%\.android\debug.keystore"

Password: android

For PowerShell

keytool -list -v -alias androiddebugkey -keystore "$env:USERPROFILE\.android\debug.keystore"

Password: android

✅ Verification

After adding fingerprints, verify that both SHA-1 and SHA-256 appear in the Firebase Console under your app settings.

6Implementation Code

Create Authentication Service

Create a new file:

lib/services/auth/auth_services.dart

AuthService Class Implementation

import 'package:firebase_auth/firebase_auth.dart';
import 'package:google_sign_in/google_sign_in.dart';

class AuthService {
    // Initialize Firebase Auth
    final FirebaseAuth _firebaseAuth = FirebaseAuth.instance;

    // Get Current User Method
    User? getCurrentUser() {
        return _firebaseAuth.currentUser;
    }

    // Email Sign In
    Future<UserCredential> signInWithEmailPassword(
        String email, 
        String password
    ) async {
        try {
            // Sign user in
            UserCredential userCredential = 
                await _firebaseAuth.signInWithEmailAndPassword(
                    email: email,
                    password: password
                );
            return userCredential;
        } on FirebaseAuthException catch(e) {
            throw Exception(e.code);
        }
    }

    // Email Sign Up
    Future<UserCredential> signUpWithEmailPassword(
        String email, 
        String password
    ) async {
        try {
            UserCredential userCredential = 
                await _firebaseAuth.createUserWithEmailAndPassword(
                    email: email, 
                    password: password
                );
            return userCredential;
        } on FirebaseAuthException catch(e) {
            throw Exception(e.code);
        }
    }

    // Google Sign In
    final GoogleSignIn _googleSignIn = GoogleSignIn();

    Future<void> signInWithGoogle() async {
        try {
            final GoogleSignInAccount? gUser = await _googleSignIn.signIn();

            if (gUser != null) {
                print('Sign in successful: ${gUser.email}');
                // Use gUser for further authentication
            } else {
                print('Sign in was cancelled');
            }
        } catch (error) {
            print('Error signing in: $error');
        }
    }

    Future<void> signOutFromGoogle() async {
        try {
            await _googleSignIn.signOut();
            print('Sign out successful');
        } catch (error) {
            print('Error signing out: $error');
        }
    }

    // Sign Out
    Future<void> signOut() async {
        return await _firebaseAuth.signOut();
    }

    // Error Message Handler
    String getErrorMessage(String errorCode) {
        switch(errorCode) {
            case 'Exception: wrong-password':
                return 'The password is incorrect. Please try again';
            case 'Exception: user-not-found':
                return 'No user found with this email. Please sign up';
            case 'Exception: invalid-email':
                return 'This email does not exist';
            default:
                return 'An unexpected error occurred. Please try again later';
        }
    }
}

7Android Build Configuration

⚠️ Required for google_sign_in ^6.2.1

If you're using google_sign_in version ^6.2.1, you need to update your Android build configuration:

Update build.gradle.kts

Open android/app/build.gradle.kts and add/modify:

Set NDK Version

android {
    ndkVersion = "27.0.12077973"
}

Update Minimum SDK Version

android {                                                                                     
    defaultConfig {                                                                             
        minSdkVersion 23                                                                          
    }                                                                                           
}

📝 Important Notes

  • These changes are specifically required for google_sign_in ^6.2.1
  • Make sure to sync your Gradle files after making these changes
  • If you encounter issues, clean and rebuild your project

9Testing & Troubleshooting

✅ Testing Checklist

  1. Verify Firebase project is properly configured
  2. Ensure all dependencies are correctly installed
  3. Check that SHA-1 and SHA-256 fingerprints are added to Firebase
  4. Confirm Google Sign-In is enabled in Firebase Console
  5. Test on both debug and release builds
  6. Verify iOS configuration if testing on iPhone/iPad

🔧 Common Issues & Solutions

  • Sign-in popup doesn't appear: Check SHA fingerprints in Firebase
  • iOS sign-in fails: Verify info.plist configuration and URL schemes
  • Build errors on Android: Ensure minSdkVersion is 23 or higher
  • Package conflicts: Use the recommended stable versions (^6.2.1 and 5.7.5)

10Best Practices

💡 Development Tips

  • Read the Documentation: Spend time reading the official package documentation when encountering issues
  • Version Control: Use specific stable versions to avoid breaking changes
  • Error Handling: Always implement proper error handling and user feedback
  • Testing: Test on multiple devices and platforms (Android & iOS)
  • Security: Never commit GoogleService-Info.plist or google-services.json to public repositories
  • User Experience: Provide clear loading states and error messages
